# Accessibility primitives

A11y components have **colocated contracts**. Before changing
`AccessibleCombobox` or `AccessibleDataGrid` (or proposing a new a11y primitive
in `components/a11y/`), read the corresponding `.contract.md`.

**Order is strict: contract first, tests second, implementation last.** If
behavior changes, update the `.contract.md` _before_ changing component code.

- `AccessibleDataGrid` **v1 uses native table semantics — not APG grid
  navigation.** Confirm this in the contract before applying APG keyboard
  expectations; do not "upgrade" it to roving-tabindex/grid nav without changing
  the contract first.
- Axe rules that need real CSS (`color-contrast`, `focus-visible`) and native
  behaviors (focus restoration, multi-keystroke sequences) belong in
  **browser-mode tests** — see `browser-tests.md`.
- Storybook runs `addon-a11y` in error mode; keep stories accessible.
